# ORI Financeiro Landing

Landing page de venda do ORI Financeiro, criada como projeto separado em React/Vite para publicar na Vercel a partir de commits no GitHub.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar

1. Suba este projeto para um repositorio no GitHub.
2. Conecte o repositorio na Vercel.
3. Use o build padrao da Vercel para Vite: `npm run build`.
4. Cada commit enviado para a branch principal publica uma nova versao.

## Alterar oferta

Edite `src/siteConfig.js` para trocar preco, WhatsApp, link do app e numeros de vagas.
